# MedAssist Prospect Intelligence

Standalone, local-first prospecting dashboard for national MedAssist prospecting.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Open **Pages** under Code and automation.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish. The public URL will normally be https://shahanrealty-cyber.github.io/medassist-prospect-intelligence/

## Data and backups
- The dashboard is a static website. It does not need a server or employer CRM connection.
- Prospect edits are saved in local browser storage on the device/browser where you make them.
- Use **Export backup (JSON)** regularly. Importing a backup replaces the current browser's dashboard data.
- CSV export is available for spreadsheet workflows.
- To move records to another browser or computer, export JSON on the first device and import it on the other.
- GitHub Pages does **not** automatically ingest hourly research alerts. Signals must be added manually unless a separate integration is built.

## Data quality
Starter entries are baseline research targets, not verified buying signals. Verify current agency details, buying authority, and any specific signal before outreach. Only label a signal verified when the linked source supports it. Avoid inferring wrongdoing or compliance failures from incomplete information.

## Privacy
This is a public repository and public website. Do not add sensitive, confidential, personal, or non-public customer information.
